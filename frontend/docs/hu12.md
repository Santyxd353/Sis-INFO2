# HU-12: horarios

Ruta protegida `/dashboard/horarios`, habilitada en navegación para los perfiles
institucionales y Profesor según permiso `horario/listar`. Requiere backend de
`Tiago` y migración `usuarios.0011_permisos_hu12`.

Incluye consulta semanal agrupada por día, selección de semana y navegación
anterior/siguiente, filtros de curso/paralelo, profesor y gestión. Los catálogos
son buscables y paginados; la lista semanal también muestra su paginación.

Con permisos de creación/edición/eliminación: formulario de asignación, aula del
colegio correspondiente, día, horas y vigencia; eliminación con confirmación.
Profesor sólo consulta sus propios horarios, con autorización adicional en API.
Tutor y Estudiante no reciben acceso nuevo como parte de esta HU.

Se muestran errores de validación y conflictos 409; un 403 bloquea nuevas
mutaciones. Los envíos se bloquean mientras están pendientes y las respuestas de
listados obsoletos no sustituyen la selección actual. Editar conserva los segundos
de horarios previamente registrados. Un horario heredado sin fecha final pide
completarla antes de guardar.

```sh
npm run test:run
npm run build
npm run lint
```

Las pruebas HU-12 ejercitan componentes reales con red simulada: CRUD, filtros,
lectura docente, errores, 403/409, catálogos/paginación, respuestas atrasadas,
operaciones en curso, precisión horaria y datos heredados.

También se verificó el flujo con API real y Chrome: crear, rechazar cruce, editar,
filtrar, consultar como profesor y eliminar. Revisión visual en escritorio y
móvil de 375 px, sin desbordamiento horizontal. Sin despliegue en Azure.
